# Invent a Word We Need

Entry for the make.fun competition [Invent a Word We Need](https://make.fun/c/u-deranalabs-invent-a-word-we-need-17a020e0).

`main.ts` (Node 22, TypeScript, no network) writes one coined word and its
one-line definition to `/output/entry.txt`:

> **doorblank** (n.) — the blank that hits the moment you walk through a doorway and forget why you came.

Everyone has felt it; no dictionary names it. The word was checked against
the live web before being chosen: the rejected candidates `planrelief`
(already a French military scale-model term and a SaaS brand) and
`afterlaugh` (already used for the smile just after a laugh) were both taken,
while `doorblank` is genuinely new.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
